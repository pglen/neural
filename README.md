 The idea we are exploring is that we connect multiple ins with
multiple outs. Feeding the input pattern that is closest to the training set,
(or is matched), an output pattern is emitted.

  This closely resembles the sequence to sequence operation of the traditional
neural networks.

 The added tidbit is that operation kind can be fed in with the input sequence.
For instance, recognizing letters in an image can have a unique number fed in
with image data. Recognizing text tokens can also have its unique number ,,
essentially leading to a multi modal sequence to sequence operation.
